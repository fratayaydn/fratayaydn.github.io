BalanceKeeper

Keeps your Mac's audio balance centered.

macOS sometimes shifts the left/right audio balance on its own, often after the volume keys are pressed while the Mac is busy. One ear gets quieter and you may not notice for days.

BalanceKeeper puts the balance back the moment it moves.

Download Source on GitHub

Features

  • Locks the balance to the center, or to any point you choose
  • Works with built-in speakers, headphones, Bluetooth and USB audio devices, and switches with them
  • Shows the current output, its balance and how often it had to correct it
  • About 3 MB of memory, no polling, no permissions and no network connections

Install

brew install --cask fratayaydn/tap/balancekeeper

Or download BalanceKeeper-<version>.dmg from the latest release, open it and drag BalanceKeeper to Applications. The app is signed with a Developer ID and notarized by Apple.

A Mac with Apple silicon, macOS 13 Ventura or later. Needs no permissions.

How it works

A small background agent asks CoreAudio to report changes to the output device and its balance, and otherwise sleeps. When the balance moves, it sets it back using the method the device supports. It uses only public macOS APIs.

More details, the build instructions and how to uninstall are in the README.
