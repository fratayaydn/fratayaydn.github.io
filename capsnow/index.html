CapsNow

Caps Lock without the delay.

macOS ignores a Caps Lock press shorter than 75 milliseconds, on purpose, so that Caps Lock does not turn on by accident. The price is that quick taps get lost: you tap Caps Lock, keep typing, and the letters come out in the wrong case.

macOS already has a setting for this delay. It just isn't in System Settings, and it resets at every restart. CapsNow sets it at login and whenever a keyboard appears, then quits.

Download Source on GitHub

Features

  • Works on every keyboard (built-in, USB and Bluetooth), including ones you connect later
  • Turning it off gives macOS its own delay back right away
  • Nothing stays running, so it uses no memory and no CPU
  • No menu bar icon and no permission to grant

Install

brew install --cask fratayaydn/tap/capsnow

Or download CapsNow-<version>.dmg from the latest release, open it and drag CapsNow to Applications. The app is signed with a Developer ID and notarized by Apple.

A Mac with Apple silicon, macOS 13 Ventura or later. Needs no permissions.

Questions

Why doesn't Caps Lock turn on when I tap it quickly?

macOS ignores a Caps Lock press shorter than 75 milliseconds on purpose, so it doesn't turn on by accident. A quick tap is shorter than that and gets lost.

Can I remove the Caps Lock delay without an app?

Yes, run hidutil property --set '{"CapsLockDelayOverride":0}' in Terminal. The setting resets at every restart, so you have to run it again. CapsNow sets the same value for you at login and whenever a keyboard is connected.

Does CapsNow keep running in the background?

No. It applies the setting and quits within two seconds, so it uses no memory or CPU the rest of the time.

How do I get the normal delay back?

Turn off Enable CapsNow and macOS's own delay is back right away.

What happens if I delete it without turning it off?

The delay stays off until the next restart. After that macOS's own delay is back, since the setting never survives a restart on its own.

How it works

It sets the HID property CapsLockDelayOverride to 0 through the public IOHIDEventSystemClient API, the same setting hidutil changes. A login item runs at login and when a keyboard appears, sets it and quits within two seconds.
