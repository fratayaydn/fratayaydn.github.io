Small Mac apps

Small fixes for things macOS keeps getting wrong. None of them has a menu bar icon. Four run as a background agent that uses about 3 MB of memory and no CPU while idle; CapsNow doesn't stay running at all.

  • NightKeys

    The keyboard light comes on when you touch the trackpad. With NightKeys only the built-in keyboard wakes it.

    MoreDownloadSource

  • BalanceKeeper

    The left/right audio balance drifts off center by itself. BalanceKeeper puts it back.

    MoreDownloadSource

  • CapsNow

    Quick Caps Lock taps get ignored. CapsNow turns off the delay that causes it.

    MoreDownloadSource

  • MicKeeper

    AirPods turn into a phone headset when macOS picks them as the mic, and an iPhone can grab it too. MicKeeper switches back to your real mic.

    MoreDownloadSource

  • FullscreenKeeper

    Quit an app in full screen and it opens as a window next time. FullscreenKeeper puts it back in full screen.

    MoreDownloadSource

Install

With Homebrew:

brew install --cask fratayaydn/tap/<name>

Or download the dmg from each app's releases page. Every app is signed with a Developer ID and notarized by Apple. They need a Mac with Apple silicon and macOS 13 or later.
