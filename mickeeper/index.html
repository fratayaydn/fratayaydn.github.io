MicKeeper

The right mic, at the right level, and AirPods that never sound like a phone call.

When AirPods or other Bluetooth headphones connect to a Mac, macOS makes them the microphone too. As soon as an app uses that microphone (a call, a Meet tab, dictation), the headphones switch to call mode and everything you hear turns mono and muffled. With an iPhone nearby, macOS may switch to its microphone instead.

MicKeeper switches the microphone back and, if you want, puts the level back too, because apps like Zoom, Teams and Chrome change it on their own.

Download Source on GitHub

Features

  • Switches back from AirPods, Bluetooth headphones and iPhone mics to the one you were using, or the built-in one
  • Pick one microphone and MicKeeper uses it whenever it is connected
  • Optionally locks the microphone level
  • About 3 MB of memory, no polling, and no permissions because it never listens to the mic

Install

brew install --cask fratayaydn/tap/mickeeper

Or download MicKeeper-<version>.dmg from the latest release, open it and drag MicKeeper to Applications. The app is signed with a Developer ID and notarized by Apple.

A Mac with Apple silicon, macOS 13 Ventura or later. Needs no permissions.

How it works

A small background agent asks CoreAudio to report changes to the default input, the device list and the input level, and otherwise sleeps. It uses only public macOS APIs.

More details, the build instructions and how to uninstall are in the README.
