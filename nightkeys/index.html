NightKeys

Only your keys wake the keyboard light.

A MacBook lights its keyboard for any input. If you use the trackpad in a dark room, the keys light up every time you scroll or move the pointer, and they stay lit as long as you keep using it. Turning the backlight off doesn't help either, because then it's dark when you do want to type.

NightKeys lights the keyboard only when you type on the built-in keyboard. Touching the trackpad, moving a mouse or typing on an external keyboard no longer wakes the light. When you stop typing, it goes off after the timeout set in System Settings > Keyboard.

Download Source on GitHub

Features

  • Optionally stays off in bright rooms, using the ambient light sensor and a threshold you pick
  • Uses the timeout, low-light mode and brightness from System Settings > Keyboard, so a change in either place shows up in both
  • About 3 MB of memory and no CPU while idle; it sleeps until you press a key
  • Never records, stores or sends what you type, and makes no network connections

Install

brew install --cask fratayaydn/tap/nightkeys

Or download NightKeys-<version>.dmg from the latest release, open it and drag NightKeys to Applications. The app is signed with a Developer ID and notarized by Apple.

A MacBook with a backlit built-in keyboard and Apple silicon, macOS 13 Ventura or later. Needs Input Monitoring, only to notice that a key on the built-in keyboard was pressed.

Questions

Why does my MacBook keyboard light turn on when I touch the trackpad?

macOS counts any input as activity: the trackpad, a mouse or an external keyboard all wake the keyboard light. There is no setting to choose which input turns it on.

Can I fix it in System Settings?

Not really. System Settings > Keyboard lets you set how long the light stays on and whether it adjusts in low light, but not what wakes it. Turning the brightness all the way down keeps it off, but then it stays dark when you type too.

Does typing on an external keyboard light up the MacBook keyboard?

Not with NightKeys. Only the built-in keyboard wakes the light, so typing on an external keyboard leaves it off.

Can NightKeys see what I type?

It needs Input Monitoring only to notice that a key on the built-in keyboard was pressed. It never records, stores or sends what you type, and it makes no network connections.

Does it work on Intel Macs?

No. It needs a MacBook with Apple silicon and a backlit keyboard.

How it works

A small background agent listens to the built-in keyboard only, so trackpad events never reach it. It controls the backlight through Apple's private CoreBrightness framework, which is why NightKeys is not on the App Store.
